# edu-k8n

Hands-on course materials on containerization and Kubernetes. Learn to package apps with Docker, orchestrate deployments in Kubernetes, scale microservice-style infrastructure, and apply GitOps workflows with FluxCD for automated, transparent delivery from Git.

## Topics

- **Containerization**: isolate applications for portability and environment independence
- **Docker & Kubernetes**: build, deploy, and operate containerized applications
- **Infrastructure scaling**: run scalable, resilient microservice-style systems
- **GitOps (FluxCD)**: continuous, controlled deployments with Git as the source of truth
